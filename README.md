# VietPanel

Web hosting control panel — mỗi user một môi trường container riêng biệt (web server, database, network, storage), VPS-grade security trên shared hardware.

- **VietPanel** — user control panel (port 2083)
- **VietAdmin** — administration panel (port 2087)
- **vietcli** — CLI quản trị bằng bash

Xem kế hoạch chi tiết: [PLAN.md](PLAN.md)

> Dự án viết lại từ đầu, tham khảo kiến trúc của OpenPanel (openpanel.com). Chưa có code — đang ở giai đoạn P1 (nền tảng chung).
