API Usage Preview

When API keys are available, you will be able to interact with VietPanel programmatically. Here is an example of what API usage will look like:

# List websites
curl -H "Authorization: Bearer $VIETPANEL_API_KEY" \
  https://your-server:8443/api/v1/websites

# Create a database
curl -X POST \
  -H "Authorization: Bearer $VIETPANEL_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"my_database","user":"db_user"}' \
  https://your-server:8443/api/v1/databases

# Check server status
curl -H "Authorization: Bearer $VIETPANEL_API_KEY" \
  https://your-server:8443/api/v1/status
